# IHO World Seas shapefile (version 3)

This directory contains the IHO Sea Areas shapefile used by
`src/shared/regions.py`. If you need to download it again:

1. Open the [Marine Regions downloads page](https://www.marineregions.org/downloads.php)
   and locate **IHO Sea Areas, version 3**. Use the download option on that page
   and complete any requested download form.
2. Extract the downloaded ZIP into this directory (`data/World_Seas_IHO_v3/`).
   Keep all files together, including `World_Seas_IHO_v3.shp`,
   `World_Seas_IHO_v3.shx`, `World_Seas_IHO_v3.dbf`, and
   `World_Seas_IHO_v3.prj`; the shapefile depends on these companion files.
3. Confirm that `World_Seas_IHO_v3.shp` is directly inside this directory.
